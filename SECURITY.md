# Security Policy

## Reporting

If you discover a security issue in this repository, email the Zynx Technologies delivery owner privately. Do not open a public issue for secrets or vulnerability details.

## Portfolio hygiene

- No production credentials, connection strings, or personal data belong in Git history.
- Use `.env.example` placeholders for configuration templates.
- Client data used for demos must be synthetic or fully anonymised.
- Rotate any credential that may have been exposed historically.

## Scope

Security expectations cover pipeline code, Databricks configs, notebooks, and documentation assets in this repository.
