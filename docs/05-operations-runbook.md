- Access to the target Databricks / compute environment when running live jobs
- Local clone of `anoopdk/sdpworkshop`
- Secrets provided via environment variables (see `.env.example`), never committed

```bash
git clone https://github.com/anoopdk/sdpworkshop.git
cd sdpworkshop
```

Then open:

1. `README.md`
2. `docs/audit/PROJECT-FACTSHEET.md`
3. `decks/overview.html`

Follow project-specific README / subtree instructions for deploy and run. Prefer fixture data for demos.
