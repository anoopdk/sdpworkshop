# Contributing

This repository is maintained as a **Zynx Technologies** delivery portfolio artifact.

## Working agreements

1. Prefer small, reviewable commits with clear intent.
2. Do not commit secrets, API keys, `.venv`, or client-identifying data.
3. Keep documentation aligned with code: update `README.md`, `docs/`, and the overview deck together.
4. Use domain-safe client naming (for example Banking Client, Logistics Client). Never publish real client legal names unless explicitly approved.
5. Open a pull request for material changes. Target `main` unless otherwise instructed.

## Local checks

- Validate notebooks and scripts run against fixture or anonymised sample data only.
- Run available unit tests before opening a PR.
- Confirm Mermaid diagrams still render after doc edits.
